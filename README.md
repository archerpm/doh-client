# DoH Client

GUI-клиент для Windows 10/11, macOS и Linux (Ubuntu 24.04 и 26.04 LTS). Направляет DNS через DoH-провайдеров, которые обходят геоблокировки (ChatGPT, Claude, Gemini, Notion, Spotify…).

## Как это работает

Провайдеры (comss, geohide, malw.link, dns-ai, mafioznik, bezmezhau, WebShift) — это DNS-резолверы, которые для геоблокированных доменов возвращают IP своего **SNI-прокси**. Прокси читает имя домена из TLS ClientHello и пересылает соединение через зарубежный сервер без расшифровки, поэтому сертификат остаётся оригинальным. Остальные домены резолвятся как обычно.

Клиент:

- поднимает локальный DNS на `127.0.0.1:53` / `[::1]:53` (UDP+TCP) и переключает на него DNS всех активных адаптеров (IPv4 и IPv6);
- шлёт запросы по DoH (RFC 8484, HTTP/2) через **один выбранный вами провайдер**: одновременно работает только один DoH-туннель, автопереключения на другие провайдеры нет (если он недоступен, клиент покажет событие, выбор меняете вы);
- **правила**: список доменов для режима hosts и подавления AAAA/HTTPS; все запросы идут через выбранный туннель. Ответ `0.0.0.0` возвращается как есть. Для доменов из правил подавляются AAAA и HTTPS/SVCB, иначе IPv6 и ECH ломают обход;
- кэширует ответы с учётом TTL, объединяет одинаковые одновременные запросы, ведёт журнал;
- режим **hosts**: домены из правил записываются в hosts без резидентного DNS;
- сохраняет исходный DNS на диск **до** изменения и возвращает его при выключении, остановке и удалении службы, а также после аварийного завершения.

## Интерфейс

Главный экран — схема маршрутов в стиле карты метро: компьютер → клиент → выбранный провайдер → ответ. По линиям в реальном времени идут запросы из журнала. Ниже — табло последних запросов. Вкладка «Проверка домена» опрашивает только выбранный туннель и показывает, ведёт ли он домен через свой прокси. Отсюда же одной кнопкой создаётся правило. При `prefers-reduced-motion` анимация отключена.

## Архитектура

```
GUI (Wails v3, без прав администратора) ──HTTP 127.0.0.1:47153 + токен──▶ Служба (SCM / launchd / systemd)
                                                                           ├─ DNS-сервер :53
                                                                           ├─ роутер: правила → кэш → выбранный DoH
                                                                           └─ системный DNS / hosts
```

Права администратора нужны один раз — на установку службы (UAC / пароль macOS / polkit). Токен API доступен только администраторам и пользователю, который установил службу: на Windows файл сразу создаётся с ACL по SID, на Unix владелец файла получает режим 0400. Если владелец неизвестен (установка из консоли без `--owner`), токен доступен только администраторам. Другие локальные пользователи не могут менять DNS системы. Пользователю без доступа GUI предложит переустановить службу из его учётной записи.

Каталог данных службы при каждом запуске проверяется. Если его создал не администратор или это ссылка, файлы внутри не принимаются на веру, а каталог получает ACL «только администраторы» (Unix: root, 0755). Это защита от подмены настроек через заранее созданный `C:\ProgramData\DohClient`.

Если исходный DNS не удаётся вернуть, клиент не выключается и служба не удаляется: система продолжает указывать на 127.0.0.1, поэтому локальный DNS обязан отвечать дальше. Перед первым изменением hosts его оригинал копируется в `hosts.original` в каталоге данных; сам hosts записывается атомарно, через временный файл и rename.

## Использование

1. Запустите `doh-client` → **«Установить службу»**.
2. **Правила** → добавьте наборы («AI-сервисы» и т. д.).
3. **Схема** → переключатель «Включить».
4. В браузере **отключите «Безопасный DNS»** (Chrome/Edge) и DoH (Firefox), иначе браузер обходит клиент.

```
doh-client service install [--owner UID|SID] | uninstall | start | stop | restart | status
doh-client run            # резолвер в консоли (от администратора), Ctrl+C восстанавливает DNS
doh-client restore-dns    # аварийное восстановление системного DNS
```

## Linux: Ubuntu 24.04 и 26.04

Проверено на 26.04 (systemd 259, GTK 4.22, WebKitGTK 2.52, AppArmor 5) с настоящим systemd-resolved и на 24.04.

- **DNS**: при systemd-resolved (стандарт Ubuntu) DNS ставится на каждый link через `resolvectl`; домены поиска сохраняются, к ним добавляется `~.`. Если NetworkManager перезаписал настройки (DHCP, смена сети), клиент через ≤20 с заново применяет свои и запоминает **актуальные** настройки сети для отката. Без resolved клиент правит `/etc/resolv.conf` (симлинк при откате тоже восстанавливается).
- **AppArmor и WebKit**: начиная с 23.10 Ubuntu запрещает непривилегированные user namespaces, а без них песочница WebKitGTK (bubblewrap) падает: «bwrap: setting up uid map: Permission denied». Установка службы кладёт AppArmor-профиль `/etc/apparmor.d/doh-client` для установленного бинарника, ярлык в меню и `/usr/local/bin/doh-client`. Если программа запущена из другого места, GUI проверяет bwrap при старте и при необходимости отключает песочницу WebKit — окно показывает только встроенные локальные файлы.
- **Трей** требует StatusNotifier: в Ubuntu он есть (расширение AppIndicator), в KDE и XFCE тоже. В чистом GNOME трея нет — тогда закрытие окна завершает приложение.
- **26.04** работает только на Wayland (GNOME 50) — поддерживается. Вместо sudo там sudo-rs: права запрашиваются через pkexec (polkit).

## Сборка

Нужен Go 1.25+ (в архиве Ubuntu 26.04 есть подходящий `golang-go`; на 24.04 — Go с go.dev).

- **Windows** (без CGO, можно кросс-компилировать): `scripts/build-windows.ps1`. На Windows 10 нужен WebView2 Runtime (обычно уже стоит вместе с Edge).
- **Linux**: `sudo apt install build-essential pkg-config libgtk-4-dev libwebkitgtk-6.0-dev`, затем `scripts/build-linux.sh`. Для 22.04 / Debian 12: `scripts/build-linux.sh gtk3` с `libgtk-3-dev libwebkit2gtk-4.1-dev`.
- **macOS**: `scripts/build-macos.sh` на Mac — универсальный `.app` (ad-hoc подпись).

Релизные сборки делаются **только с тегом `production`** (так в скриптах). Без него Wails собирается в dev-режиме: появляются инструменты разработчика, а переменная `FRONTEND_DEVSERVER_URL` может подменить встроенный интерфейс внешним адресом.

Тесты: `go test -race ./...`. Живые запросы к провайдерам: `go test -tags live ./internal/doh -run Live -v`.

## Файлы

| ОС | Данные службы | Бинарник службы |
|---|---|---|
| Windows | `%ProgramData%\DohClient` | `%ProgramFiles%\DohClient\doh-client.exe` |
| macOS | `/Library/Application Support/DohClient` | `…/DohClient/bin/doh-client` |
| Linux | `/var/lib/doh-client` | `/usr/local/lib/doh-client/doh-client` |

`config.json` — настройки, `dns-backup.json` — исходный DNS (существует, только пока DNS переключён), `owner` — кому разрешён доступ к службе, `service.log` — журнал службы.

## Ограничения

- Работает только для доменов из списков провайдера. Привязка к стране на уровне аккаунта или оплаты не обходится.
- Включённый VPN перехватывает DNS — правила клиента при этом не действуют.
